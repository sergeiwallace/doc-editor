# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the work. Harassment,
personal attacks and discriminatory language are not accepted in issues, pull requests or any other
project space.

## Reporting

Report a problem to the maintainer, [@sergeiwallace](https://github.com/sergeiwallace). For a
sensitive matter, use the private report form on the repository's **Security** tab rather than a
public issue. Reports are handled in confidence.

## Enforcement

The maintainer may edit or remove comments, commits and issues that break this code, and may ban a
contributor who breaks it repeatedly, following the enforcement guidelines of the Contributor
Covenant.
