# Test

Test documentation, coverage reports, and UAT tracking.

## What belongs here
- UAT (User Acceptance Testing) plans and results
- Test coverage reports and unit test documentation
- UAT template for new features (`uat-template.md`)
- Fixture documents a live check opens in the pane (`fixtures/`): generated by `plugins/doc-editor/core/fixture-docs.ts` and checked byte for byte by `test/fixture-doc.spec.ts`

## What does NOT belong here
- Actual test code (Python fixtures, conftest) -> lives in `tests/` at project root
- Bug investigations -> use `bugs/` instead
- Research on testing strategies -> use `research/` instead
