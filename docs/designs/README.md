# Designs

Sub-system architecture blueprints and design documents.

## What belongs here
- Architecture and design docs for major sub-systems
- Tradeoff analysis for significant technical decisions
- System interaction diagrams and data flow descriptions
- Must link to `designs/architecture.md` for platform-level context

## Templates
- `TEMPLATE.md` — sub-system design doc (decisions, data model, integration)
- `ARCH-TEMPLATE.md` — top-level architecture overview (layers, components, philosophy)

## What does NOT belong here
- Task breakdowns and implementation steps -> use `plans/` instead
- External research with citations -> use `research/` instead
- Long-term vision and strategy -> use `vision/` instead
- Tradeoff analyses from ad-hoc discussions -> use `analysis/` instead
